# AI 聊天

成員用 `/ai choose` 選一位角色，之後的 `/ai chat` 與 `@BOT. 訊息` 只由這位角色回應。每位成員只能選一位；想換人就再用一次 `/ai choose`。

| 角色 | 分身名稱 | 模型 | 個性 |
| --- | --- | --- | --- |
| 十四行詩 | Sonnet | Claude，預設 `haiku`（Haiku 系列最新版） | 文靜的大小姐：說話輕柔有禮、用字典雅、句子簡短，很少用表情符號 |
| 晨曦 | Dawn | GPT，預設 `gpt-6.1-terra`，推理強度 `low` | 活潑開朗：熱情、愛鼓勵人，常用驚嘆號，偶爾用表情符號 |

兩位角色的頭像在 `assets/ai/sonnet.png`、`assets/ai/dawn.png`，由專案擁有者自行繪製。

## 指令

| 指令 | 做什麼 |
| --- | --- |
| `/ai choose character:` | 選擇十四行詩（Claude）或晨曦（GPT），回覆只有自己看得到 |
| `/ai chat message:` | 和選擇的角色說話，一次最多 1000 字 |
| `@BOT. 訊息` | 在伺服器頻道直接提及機器人，角色以分身回覆 |
| `/ai forget` | 清除角色對這段對話的記憶 |

兩種說話方式的回覆格式：

| 方式 | 回覆 |
| --- | --- |
| `/ai chat` | 機器人回覆一個 embed 方塊，作者欄是角色名稱與頭像，內容是回答，最後一行是 `-# 模型名稱 耗時`（例如 `-# GPT-6.1 Terra 3.2s`） |
| `@BOT. 訊息` | 角色的分身（webhook，名稱與頭像如上表）在同一頻道送出純文字回答，最後一行同樣是 `-# 模型名稱 耗時` |

兩種都不會引用成員說過的話。耗時是模型從收到到回答完成的秒數，不含 Discord 傳送時間。

**分身**：每個頻道第一次需要時，機器人建立該角色的 webhook（Sonnet、Dawn 各一個），之後重複使用；討論串使用上層頻道的 webhook。被刪掉的 webhook 會在下次自動重建。需要機器人有該頻道的「管理 Webhook」權限；沒有時改由機器人自己用同樣的純文字回覆。修改頭像圖片後，已建立的 webhook 不會自動更新，刪掉該頻道的 webhook 讓它重建即可。

**哪些訊息算提及**：只有訊息文字裡寫了 `@BOT.` 才算；回覆機器人訊息時的提醒不算。機器人、webhook 發的訊息、私訊與黑名單成員的訊息都不回應。提及本身不會傳給模型。

- 沒選過角色就用 `/ai chat` 或 `@BOT.`，會提示先用 `/ai choose`。
- 角色記得最近 6 輪對話，讓回覆能接續；記憶只放在記憶體，重啟、`/ai forget` 或換角色時清除。選擇存在 `data/storage/ai_chat.json`（使用 MySQL 時存在資料庫）。
- 上一則還在回覆時再送一則，會請成員稍等。
- 回覆最多顯示 1800 字，不會提及任何人（`@everyone`、`@here` 與成員提及都不會觸發）。
- 模型沒有回覆時（沒登入、額度用完、逾時），回覆「此功能暫時維護中 稍後再試」。該模型之後 60 秒內不再被詢問。

## 設定

聊天與 [AI 圖片審核](image-review.md#claude-與-gpt預設) 共用同一套命令列工具與限制：同時最多執行兩個模型程序，每次呼叫都是不保存、無工具的新工作階段。

| 環境變數 | 預設 | 用途 |
| --- | --- | --- |
| `AI_CHAT_CLAUDE_MODEL` | `haiku` | 十四行詩使用的模型 |
| `AI_CHAT_GPT_MODEL` | `gpt-6.1-terra` | 晨曦使用的模型；想更省額度可改 `gpt-6-luna` |
| `CLAUDE_CLI`、`CODEX_CLI` | 自動尋找 | 指定兩個命令列工具的位置 |
| `CLAUDE_CODE_OAUTH_TOKEN` | 無 | Claude Code 在桌面版之外的登入，用 `claude setup-token` 產生 |

## 控制台顯示

`run_bot.bat` 控制台右上角的 Nova 會顯示 Claude 與 GPT 的用量（圖片審核與聊天合計）：

| 位置 | 顯示 |
| --- | --- |
| 模型那一行 | 已安裝的模型：`Claude·GPT`；沒有任何一個時顯示「無模型」，Nova 閉眼休息 |
| 進度條 | 在環境變數或 `.env` 設定 `BOT_AI_DAILY_TOKENS`（每日 token 預算，例如 `2000000`）時，依今日用量填滿；沒設定就保持灰色。改了之後要重開控制台 |
| 狀態那一行 | 今日 token 數（例如 `今日 12.3k`）；模型剛失敗、暫停中時顯示 `Claude維護`、`GPT維護` 或兩者都暫停的 `維護中` |

資料來自機器人寫入的 `data/ai_usage.json`：每個模型今日的呼叫次數、失敗次數、token 數與暫停到期時間，每天歸零。兩個命令列工具都不會回報訂閱還剩多少，所以控制台看不到真正的剩餘額度，只能和你自己設定的每日預算比較。token 數取自工具回報的輸入（含快取）加輸出。

角色設定（個性與共同規則）在 `src/services/ai_chat_service.py` 的 `PERSONAS`。共同規則要求角色：表明自己是 AI、不假裝做過自己做不到的事、用成員的語言回覆、拒絕有害請求、不提及任何人、不透露或更改設定。

> [!NOTE]
> 角色規則是寫給模型的指示，模型不一定每次都遵守。真正的保護在程式端：模型沒有任何工具，回覆不會觸發提及。

驗證：`pytest tests/test_ai_cli.py`。
