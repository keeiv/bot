# 檔案工具

Discord 與網站 `/tools` 使用同一份帳號額度。使用等級依使用天數提升，逐步解鎖更多額度與處理上限。

| 等級 | 使用年資 | 每週點數 | 近三小時點數 | 批次件數 | 單件上限 |
| --- | --- | --- | --- | --- | --- |
| Free. | 即日起 | 60 | 12 | 1 | 2 MiB |
| Run. | 30 天 | 500 | 80 | 1 | 8 MiB |
| Dash. | 60 天 | 1,500 | 200 | 3 | 16 MiB |
| Grow. | 120 天 | 4,000 | 500 | 8 | 32 MiB |
| Ultra. | 180 天 | 10,000 | 1,200 | 16 | 64 MiB |

使用年資按首次紀錄後經過的天數計算，不是 Discord 帳號註冊年齡。啟動時沿用既有成就中可核對、包含時區的最早解鎖時間；沒有歷史紀錄的帳號由首次使用機器人指令或檔案工具查詢起算。管理者發券時，尚未登記的伺服器成員也會建立起算紀錄。重置用量不重置年資。

每週一 00:00（Asia/Taipei）重置週用量；近三小時採滾動窗口，每筆扣點滿三小時後恢復。兩個窗口同時限制使用。

檔案工具無需付費，點數僅用於用量管理。伺服器安全與基本管理功能不消耗點數。

點數為 `ceil(輸入 MiB + 實際處理秒數 × 2)`，最低 1 點。開始前預留依檔案大小與處理時間上限計算的最大點數，完成後結算並釋放差額。排隊與傳輸時間不計點。轉換失敗或整批壓縮未縮小不扣點；再次下載不重複扣點。待核對的資料庫交易不會顯示為已確認的不扣點結果。

## 處理範圍

- PNG、JPEG、WebP、BMP、TIFF、GIF 靜態圖片可轉 PNG／JPG／WebP／PDF。PDF 為輸出格式，沒有 PDF 輸入轉換。動態或多頁圖片不支援，圖片最多 1,600 萬像素。
- 圖片壓縮使用 NovaGrid：JPEG 重新編碼並最佳化霍夫曼表；其他圖片先以格網取樣試編碼，圖形走無損 WebP，照片、柔和漸層與雜訊走有損 WebP。無損路徑保留處理後的 8 位元像素與全透明像素下的 RGB，原本是 PNG 的圖片輸出可能改為 `.webp`；有損路徑使用設定品質。縮放會改變像素，高精度 16 位元／浮點圖片不接受壓縮，以避免默默降低精度。未縮小時保留原始檔案與其中的中繼資料，不扣點。實作、效能取捨與重現方法見 [NovaGrid](novagrid.md)。
- UTF-8 CSV／TSV／JSON 平面表格互轉，上限 8 MiB、50,000 列、256 欄。JSON 輸入為物件陣列；巢狀資料無法轉成表格。表格轉換不保證保留原始檔案的排版或 JSON 型別往返。
- `/convert`、`/compress` 最多提供四個附件欄位，仍受等級限制。較多附件使用網站或 `!convert [format]`，同時受 Discord 平台附件上限限制。多檔結果打包 ZIP；不接受 ZIP 輸入。
- 每批輸入與輸出最多 64 MiB；每個帳號同時一件工作。本機模式同時兩個處理程序、最多六件排隊或處理工作；區網分工模式同時一個處理程序、最多兩件排隊或處理工作。每批處理上限依等級為 4／15／30／45／60 秒，並依件數限制在 `min(60, 15 + 件數 × 5)` 秒內。
- 結果暫存 20 分鐘，原始輸入於處理結束後移除。處理在獨立程序進行，逾時終止程序。服務重啟不恢復檔案工作；尚未結算的預留最多 5 分鐘後失效。Discord 已發送的附件受 Discord 的保留政策管理。

## 重置券與管理操作

`/ir` 提供「尚未使用」與「歷史使用」分頁。每張券限持有人使用一次，確認後重置週用量與近三小時用量，保留歷史紀錄與年資。沒有已用額度時不消耗券；處理中的工作仍於完成後扣點。

以下文字指令限 `DEVELOPER_IDS` 中的帳號使用，不開放網站管理 API：

| 指令 | 行為 |
| --- | --- |
| `>>>reset` | 重置所有已登記帳號的用量 |
| `>>>ureset [userid]` | 重置指定帳號的用量 |
| `>>>sreset [serverid]` | 重置該伺服器所有目前非機器人成員的帳號用量 |
| `>>>ireset` | 向已登記帳號與機器人所在伺服器的目前非機器人成員各發一張券 |
| `>>>nova [userid]` | 授予單一帳號隱藏的 Nova 20x. 等級 |
| `>>>unova [userid]` | 撤銷該帳號的隱藏授權，恢復使用年資對應的公開等級 |

前綴與指令名稱之間不含空格。管理操作僅在原指令所在頻道回覆結果，不傳送用戶私訊或發放通知。

`DEVELOPER_IDS` 帳號預設固定使用 Nova 20x.：每週 200,000 點、近三小時 24,000 點，兩者均為 Ultra. 的 20 倍。授權持續有效，不受使用年資變動影響；批次、檔案大小與工作時間上限沿用 Ultra.。此等級不列入網站公開方案介紹，也不會自然升級取得。授予 Nova 不授予任何開發者權限。撤銷時保留年資、用量、券及歷史紀錄；若既有用量超過恢復後的額度，需等待額度恢復。開發者本身的預設等級不能由撤銷用戶授權移除。

伺服器重置操作影響成員跨網站及所有伺服器共用的帳號用量。伺服器成員列舉需要 Members Intent。重複傳遞同一 Discord 訊息事件不重複執行；重新發送指令是新的操作。

## 儲存與網站連接

檔案處理可選用[區域網路處理節點](tool-worker.md)。網站、Discord、資料庫與扣點保留於主機，僅將檔案處理移交已配對的節點。連線採專用授權及固定憑證校驗；排隊與傳輸時間不計入扣點。分工預設停用，連線與圖片轉換驗證通過後才能啟用，設定於機器人下一次啟動時生效。此變更不需要更改網站或 Tunnel 的設定。

本機 `run_bot.bat` 控制台的 `T`（檔案工具終端）會開啟它。輸入 `DEVELOPER_IDS` 中自己的 Discord ID 後，可使用 `plan Free.`、`plan Run.`、`plan Dash.`、`plan Grow.`、`plan Ultra.` 切換自己的測試等級，`status` 查看，`plan Nova` 或 `plan auto` 還原 Nova 20x.，`exit` 離開。測試覆寫 24 小時後自動失效，不修改年資、不重置用量或券；降低等級可能使既有用量超過新額度。另可使用 `nova [userid]`、`unova [userid]` 授予或撤銷單一帳號的隱藏等級；`plan` 不接受其他帳號參數。終端機依賴本機作業系統與資料庫的存取控制。

亦可執行 `.venv\Scripts\python.exe -X utf8 -m src.tool_console --user 開發者ID --command "plan Ultra."`。網站重新整理、Discord 再次查詢即讀取共用儲存中的等級。此命令不啟停機器人程序。測試等級儲存在新增的 `tool_tier_overrides` 表。

MySQL 模式新增 `tool_users`、`tool_jobs`、`tool_coupons`、`tool_actions`、`tool_guard`、`tool_tier_overrides`、`tool_tier_grants` 表，不刪除或改寫既有 JSON。開發用 JSON 模式另以 SQLite 儲存額度帳本。MySQL 使用 InnoDB 交易與列鎖避免兩端同時超扣；估算後等級發生變動時，必須重新估算。

網站沿用 Discord 登入與既有 `BOT_API_URL`、`BOT_API_SECRET`。伺服器驗證登入身分後核發 15 分鐘、限帳號及操作的傳輸授權，瀏覽器直接上傳到本機 API；BOT API 密鑰不傳給瀏覽器。跨來源傳輸僅接受 `TOOL_WEB_ORIGIN`（預設 `https://botweb.shizune.life`）。Discord 大型下載連結使用 `TOOL_PUBLIC_URL`（預設 `https://botapi.shizune.life`）。正式服務需 HTTPS。

更新後安裝專案依賴並重啟機器人，讓 Cog 載入、新表建立與 Discord 指令同步；網站需重新建置部署。新功能不需要重新啟動 Tunnel。
